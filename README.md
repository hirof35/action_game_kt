Kotlin Mario: Boss Battle EditionKotlinとSwingを使用して開発された、レトロスタイルの2Dプラットフォーム・アクションゲームです。物理ベースのジャンプ挙動、敵の踏みつけ、そして最後に待ち受けるボス戦を実装しています。🎮 ゲームの特徴物理演算ジャンプ: 重力加速度をシミュレート。ボタンの入力時間によって跳躍の高さが変わる「可変ジャンプ」を搭載しています。踏みつけシステム: 敵（オレンジ）の頭上から衝突すると撃破でき、反動でマリオが跳ね上がります。ボス戦 (Final Stage): 雑魚敵を3体倒すと、画面を左右に高速移動する巨大なボス（マゼンタ）が出現します。ゲーム状態管理: コースクリア、ゲームオーバー、リスタート（Rキー）のフローを完備。🕹 操作方法キーアクション← / →左右に移動Spaceジャンプ（空中で踏みつけると高く跳ねる）Rゲームオーバー/クリア後のリスタート🚀 始め方前提条件Java Development Kit (JDK) 8 以上Kotlin コンパイラコンパイルと実行リポジトリをクローンし、ターミナルで以下のコマンドを実行してください。Bash# コンパイル
kotlinc MarioGame.kt -include-runtime -d MarioGame.jar
